Job Finder

Aplicação web desenvolvida com React para simular uma plataforma de vagas, com foco em aprendizado, prática de desenvolvimento Front-End e demonstração de habilidades técnicas.

O projeto está em desenvolvimento contínuo e tem como objetivo aplicar na prática conceitos de criação de interfaces, autenticação de usuários, organização de código e integração com serviços externos.

Sobre o projeto

O Job Finder é um projeto pessoal desenvolvido para aprimorar minhas habilidades como desenvolvedor Front-End.

A aplicação simula uma plataforma de busca de vagas, permitindo explorar conceitos utilizados em aplicações reais, como:

- Autenticação de usuários;
- Navegação entre páginas;
- Consumo e armazenamento de dados;
- Organização de componentes;
- Desenvolvimento de interfaces responsivas.

O objetivo principal do projeto não é representar uma plataforma comercial finalizada, mas sim demonstrar minha evolução técnica e minha capacidade de construir aplicações utilizando tecnologias modernas.

Funcionalidades desenvolvidas

- Cadastro de usuários;
- Login e logout utilizando Firebase Authentication;
- Persistência da sessão do usuário;
- Dashboard personalizado;
- Busca de vagas;
- Filtro de pesquisa;
- Exibição de vagas em destaque;
- Página de perfil com informações do usuário;
- Sistema de rotas para navegação entre páginas;
- Layout responsivo com abordagem mobile first.

Funcionalidades em desenvolvimento
